# KB-1754: Consolidate sync and async fs imports in bridge-manager.ts

## Summary

`bridge-manager.ts` imported both `import * as fs from 'fs'` (sync) and `import { readFile } from 'node:fs/promises'` (async). The sync import was used only once for `fs.realpathSync()` in `fetchVersionInfoInternal()`. Replaced with `await realpath()` from `node:fs/promises` and removed the redundant sync import. The method was already async, so this added no structural change.

## Key Files Changed

- packages/pike-lsp-server/src/services/bridge-manager.ts: Added `realpath` to the `node:fs/promises` import, removed `import * as fs from 'fs'`, replaced `fs.realpathSync(pikePath)` with `await realpath(pikePath)`.
