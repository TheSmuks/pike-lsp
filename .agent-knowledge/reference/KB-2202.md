# KB-2202: Clean up type casts and duplicated handler types in test infrastructure

## Summary
PR #2202 introduced `asServices()` as the canonical pattern for mock-to-Services casts, but one file still used raw `as unknown as Services`. Additionally, handler type aliases (DefinitionHandler, ReferencesHandler, etc.) were duplicated between test-helpers.ts and mock-services.ts. A formatting-only change in pike-introspection.ts was unrelated to the PR's purpose, and imports were placed before the JSDoc comment in document-open-race.test.ts.

## Key Files Changed
- `prewarm-auto-import.test.ts`: Replaced `as unknown as Services` with `asServices()`, removed unused `Services` type import
- `pike-introspection.ts`: Reverted formatting-only change (`async modulePath =>` back to `async (modulePath) =>`)
- `test-helpers.ts`: Removed 59 lines of duplicated handler type aliases, imported them from mock-services.ts instead (559 → 511 lines)
- `document-open-race.test.ts`: Moved imports after JSDoc comment to match codebase convention
