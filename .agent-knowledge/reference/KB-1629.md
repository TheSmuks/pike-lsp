# KB-1629: Remove regex member access workarounds

## Summary

Two regex-based functions (`resolveArrowWorkaround` using `/(\w+)\s*->\s*$/` and `resolveModuleDotWorkaround` using `/([A-Z][a-zA-Z0-9_]*)\.\s*$/`) were removed from `completion-member-access.ts`. These were fallbacks used when the Pike bridge `getCompletionContext()` did not detect `member_access` or `scope_access`. All existing completion tests already provide bridge context with `context: 'member_access'`, confirming the bridge path covers these cases. The now-unused `resolveMembersFromWorkspace` helper (only called by `resolveArrowWorkaround`) was also removed. Commit `23102bd` had previously reordered the code to try the bridge first, but kept the regex fallbacks "for robustness." This change completes the removal.

## Key Files Changed

- packages/pike-lsp-server/src/features/editing/completion-member-access.ts: Removed `resolveArrowWorkaround`, `resolveModuleDotWorkaround`, and `resolveMembersFromWorkspace` (all regex-based or dead code)
- packages/pike-lsp-server/src/features/editing/completion.ts: Removed imports of the two deleted functions and their fallback call sites after the bridge context check
