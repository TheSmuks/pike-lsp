# KB-1546: Parallelize background diagnostic batch processing

## Summary

Background diagnostic batch processing was sequential — each file in a batch awaited `bridge.analyze()` one at a time. Since analyze calls are independent (no shared state), they can run concurrently. Replaced the sequential for-loop with `Promise.allSettled()` so a batch completes in the time of the slowest file rather than the sum of all files.

## Key Files Changed

- packages/pike-lsp-server/src/services/workspace-diagnostics.ts: Replaced sequential for-loop in `processBatch()` with `Promise.allSettled(batch.map(...))` for concurrent file analysis within each batch
