# KB-1948: Replace unsafe NodeJS.ErrnoException cast with instanceof check

## Summary

Line 232 in `file-watcher.ts` used `(err as NodeJS.ErrnoException).code === 'ENOENT'` — an unsafe type assertion that silently succeeds on non-ErrnoException errors. Replaced with `err instanceof Error && 'code' in err` guard, matching the pattern already used in `lifecycle.ts`.

## Key Files Changed

- packages/pike-lsp-server/src/features/file-watcher.ts: Added `instanceof Error` and `'code' in err` guard before the ENOENT check on line 232.
