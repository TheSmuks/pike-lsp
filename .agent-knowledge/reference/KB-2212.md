# KB-2212: Add unbounded-growth guard to DocumentCache

## Summary

DocumentCache used a raw Map with no size limit, allowing unbounded growth when scanning large workspaces. Replaced the internal Map with the project's existing `LRUCache` from `utils/lru-cache.ts`, adding a configurable `maxSize` constructor parameter (default 2000) with automatic LRU eviction of least-recently-accessed entries.

## Key Files Changed

- `packages/pike-lsp-server/src/services/document-cache.ts`: Replaced `Map<string, DocumentCacheEntry>` with `LRUCache<string, DocumentCacheEntry>`. Added constructor parameter `maxSize` (default 2000). Updated `entries()` to wrap LRUCache's array return as IterableIterator. Updated `size` getter to use `entryCount`.
- `packages/pike-lsp-server/src/scenarios/document-cache.test.ts`: Added 6 test cases for LRU eviction behavior (eviction on overflow, get refreshes position, default 2000 capacity, custom maxSize, entries() post-eviction, overwrite without eviction).
- `packages/pike-lsp-server/src/testing/property-tests/cache-invariants.test.ts`: Added property test verifying `cache.size <= maxSize` invariant for arbitrary operation sequences.
