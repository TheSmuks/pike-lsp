# KB-2199: Integrate PUnit test runner into CI pipeline

## Summary

The PUnit testing framework was added in #2196 with `test/punit/foundation-tests.pike` as the first migrated test. This change adds the PUnit runner (`./scripts/run-punit-tests.sh --ci`) to the CI `pike-test` job alongside the existing legacy test runner (`./scripts/run-pike-tests.sh`). The migrated `test/tests/foundation-tests.pike` was removed from the legacy suite. Remaining legacy tests (analysis, cross-version, e2e-foundation, intelligence, mixed-content, module-load, parser, response-format, smoke) are kept until their PUnit migrations are complete.

## Key Files Changed

- `scripts/run-pike-tests.sh`: Commented out foundation-tests (migrated to PUnit)
- `test/tests/foundation-tests.pike`: Removed (migrated to `test/punit/foundation-tests.pike`)
- `AGENTS.md`: Added PUnit runner to verification commands and test infrastructure list
- `CONTRIBUTING.md`: Added PUnit test step to pre-merge checklist
- `docs/compatibility-notes.md`: Updated test coverage section to mention PUnit
- `docs/specs/query-engine-v2-promotion-evidence-pack.md`: Added PUnit gate requirement
- `scripts/run-qe2-promotion-gates.sh`: Added PUnit test step
