# KB-2170: diagnosticsPublished not populated after createMockConnection migration

## Summary
PR #2202 moved `createMockConnection` from `mock-services.ts` to `test-helpers.ts`. The new implementation pushed diagnostics to `_sentDiagnostics` (returned by `getSentDiagnostics()`) but forgot to also push to the public `diagnosticsPublished` array, causing `diagnostics-flood.stress.test.ts` to fail.

## Key Files Changed
- `packages/pike-lsp-server/src/tests/helpers/test-helpers.ts`: Added `diagnosticsPublished.push(params)` inside `sendDiagnostics()` so both `_sentDiagnostics` and `diagnosticsPublished` stay in sync.
