# KB-2170: Remove as-unknown casts from createMockConnection overrides

## Summary

Scenario tests were using `(conn as { sendDiagnostics: ... }).sendDiagnostics = ...` and `(conn as { console: { error: ... } }).console.error = ...` patterns to override mock connection methods. Since `MockConnection` interface exposes `sendDiagnostics` and `console.error` as mutable properties, direct assignment (`conn.sendDiagnostics = ...`, `conn.console.error = ...`) works without any casts.

## Key Files Changed

- fault-bridge-crash.test.ts: Replaced `as unknown` cast patterns for sendDiagnostics/console.error overrides with direct property assignment
- fault-bridge-restart.test.ts: Same pattern
- fault-invariant.test.ts: Same pattern
- code-actions-parse-resilience.test.ts: Removed unnecessary `originalConsoleError` intermediate variable and `as` cast
- code-lens-parse-resilience.test.ts: Same pattern
- document-open-race.test.ts: Replaced `(services as any).documentCache` override with destructured spread + `asServices()`, replaced `{ get: () => undefined } as any` with `createMockDocuments()` + `asTextDocuments()`
