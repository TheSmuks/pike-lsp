# KB-1557: Split tag-catalog.ts to meet 500-line limit

## Summary

tag-catalog.ts was 1156 lines, 2.3x the 500-line limit. The file contained type definitions, ~1011 lines of RXML tag data constants, and query functions. Split into 5 files: tag-catalog-types.ts (shared types), tag-catalog-output.ts (output/control/loop/scope tags), tag-catalog-content.ts (content/HTTP/form/utility tags), tag-catalog-advanced.ts (advanced/image/misc tags), and tag-catalog.ts (thin re-export + query API). A shared types file was needed to break circular dependencies since data files import types and the main module imports data.

## Key Files Changed

- tag-catalog.ts: Reduced from 1156 to 142 lines. Now imports types from tag-catalog-types.ts, imports data from 3 data files, and provides query functions + re-exports.
- tag-catalog-types.ts: New file with RXMLTagType, RXMLAttribute, RXMLTag interfaces.
- tag-catalog-output.ts: New file with OUTPUT_AND_CONTROL_TAGS array (output, conditional, loop, scope tags).
- tag-catalog-content.ts: New file with CONTENT_AND_UTILITY_TAGS array (string manipulation, headers, includes, form, utility tags).
- tag-catalog-advanced.ts: New file with ADVANCED_AND_MISC_TAGS array (advanced, image, file, macro, client, cookie, prestate tags).
