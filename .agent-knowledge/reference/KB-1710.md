# KB-1710: Remove unsafe double cast for stdlib synthetic symbol

## Summary

The stdlib module lookup fallback in `hover.ts` created a synthetic `PikeSymbol` using `as unknown as PikeSymbol`. The object literal was already structurally compatible with the `PikeSymbol` interface (all fields including `range`, `selectionRange`, `children`, `modifiers` match the interface's optional fields). The `unknown` intermediate cast was unnecessary and bypassed TypeScript's structural checking. Replaced with a simple `as PikeSymbol` cast.

## Key Files Changed

- packages/pike-lsp-server/src/features/navigation/hover.ts: Replaced `as unknown as PikeSymbol` with `as PikeSymbol` on the synthetic stdlib module symbol (line 414).
