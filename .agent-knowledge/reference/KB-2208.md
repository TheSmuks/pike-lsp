# KB-2208: Log caught errors in cache-builder dependency resolution

## Summary

Two catch blocks in cache-builder.ts (`buildCacheWithIntrospection` and `buildCacheParseOnly`) silently swallowed errors from `resolveDependenciesViaBridge` with only a code comment. Added `log.debug` calls with the URI and error message to make bridge resolution failures observable in logs while preserving graceful degradation.

## Key Files Changed

- packages/pike-lsp-server/src/features/diagnostics/cache-builder.ts: Added `log.debug('Bridge dependency resolution failed', ...)` to two catch blocks (lines 140 and 254), following the same pattern as workspace-diagnostics.ts.
