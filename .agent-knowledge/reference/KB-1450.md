# KB-1450: Extract shared symbol-position matching helpers in symbol-index

## Summary

`buildSymbolPositionIndex` and `buildSymbolPositionIndexRegex` both independently built `symbolNames` sets, `definitionLines` maps, and iterated over tokens with identical filtering logic (skip definition lines, skip comments, check word boundaries). This duplication meant any change to definition-line detection or token filtering had to be applied in two places. Extracted `extractSymbolMatchMetadata()` and `matchTokensToSymbolPositions()` as shared internal helpers.

## Key Files Changed

- packages/pike-lsp-server/src/features/diagnostics/symbol-index.ts: Extracted `extractSymbolMatchMetadata()` and `matchTokensToSymbolPositions()` helpers; refactored both `buildSymbolPositionIndex` and `buildSymbolPositionIndexRegex` to use them, eliminating ~60 lines of duplicated logic.
