# KB-1926: Concurrency-limited file reads and bounded batch key in workspace diagnostics

## Summary

`processBatch()` in `workspace-diagnostics.ts` previously used `Promise.allSettled` to read all batch files concurrently (unbounded I/O) and concatenated all URIs into the scheduler key (`uriList.join(',')`), which grows unboundedly for large batches. Replaced with a simple semaphore (MAX_CONCURRENT=10) that limits concurrent `fs.readFile` calls, and replaced the scheduler key with `computeContentHash(uriList.join('\0'))` for a fixed-size deduplication key. Analysis is now sequential after reads complete, which also simplifies error handling.

## Key Files Changed

- packages/pike-lsp-server/src/services/workspace-diagnostics.ts: Added `computeContentHash` import, replaced `Promise.allSettled` file reads with semaphore-limited concurrent reads followed by sequential analysis, replaced unbounded URI join key with hash-based key.
