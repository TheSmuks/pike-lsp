# KB-2149: Bridge startup error classification

## Summary

Document validator caught bridge startup failures but only logged a generic warning (`Failed to start bridge: ${err}`). Added `classifyBridgeStartupError()` to distinguish ENOENT (Pike not found vs script not found), EACCES/EPERM (permission denied), pipe failures, timeouts, and unknown errors. Each classification includes user-facing message, actionable suggestion, and diagnostic details.

## Key Files Changed

- `packages/pike-lsp-server/src/utils/bridge-startup-errors.ts`: New error classifier with `classifyBridgeStartupError`, `createVersionErrorDetails`, `formatBridgeStartupError`
- `packages/pike-lsp-server/src/features/diagnostics/document-validator.ts`: Replaced generic error string with classified error output
- `packages/pike-lsp-server/src/utils/compatibility.ts`: Exported `MIN_SUPPORTED_VERSION` for use in version error details
