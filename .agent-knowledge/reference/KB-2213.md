# KB-2213: Revert unrelated formatting changes in PR #2213

## Summary
PR #2213 introduced two unrelated formatting changes (not connected to issue #2208): collapsing a multi-line Promise callback to a single line in lifecycle.ts, and adding unnecessary parentheses to a single-param arrow function in pike-introspection.ts. Both were reverted to match origin/main.

## Key Files Changed
- packages/pike-lsp-server/src/features/diagnostics/lifecycle.ts: Restored 3-line Promise constructor callback (was collapsed to single line)
- packages/pike-lsp-server/src/services/pike-introspection.ts: Removed unnecessary parens from `async (modulePath) =>` → `async modulePath =>`
