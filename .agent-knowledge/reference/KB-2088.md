# KB-2088: Fix PR #2088 review feedback

## Summary

PR #2088 (perf: Optimize WorkspaceIndex symbol lookup) had review issues: (1) unrelated formatting-only changes to RXML parser/test files were reverted, (2) performance tests measured LRU cache-hit speed instead of actual trigram index performance because searchCache was never cleared between iterations — fixed by adding `beforeEachRun` callback to `measureP95` that clears the cache, (3) thresholds adjusted from unrealistic <1ms to honest <50ms prefix / <500ms substring to reflect actual cold-cache trigram index performance with 100K symbols, (4) three unused static constants (`SUBSTRING_INDEX_MIN_LENGTH`, `SUBSTRING_INDEX_MAX_SIZE`, `SUBSTRING_INDEX_EVICT_BATCH`) removed from `WorkspaceIndex` since tests import directly from `workspace-index-search.ts`.

## Key Files Changed

- packages/pike-lsp-server/src/features/rxml/parser.ts: Reverted unrelated formatting change (multi-line signature back to single line).
- packages/pike-lsp-server/src/tests/features/rxml/parser.test.ts: Reverted unrelated formatting changes.
- packages/pike-lsp-server/src/tests/symbols/workspace-index-lookup-perf.test.ts: Added `clearSearchCache` helper, updated `measureP95` with `beforeEachRun` callback, both perf tests now clear cache between iterations, reduced iterations from 100 to 10, adjusted thresholds to realistic values.
- packages/pike-lsp-server/src/workspace-index.ts: Removed three unused static constants and their corresponding imports.
