# KB-2188: Resolution cache file size limits

## Summary

Resolution cache loading read files without size checks, allowing unbounded memory allocation on corrupted/truncated writes. Added `fs.stat` pre-check (MAX_CACHE_FILE_SIZE=10MB) before reading, data string length validation (MAX_CACHE_DATA_SIZE=8MB) after parsing, and save-side serialization size guard.

## Key Files Changed

- packages/pike-lsp-server/src/constants/index.ts: Added MAX_CACHE_FILE_SIZE (10MB) and MAX_CACHE_DATA_SIZE (8MB) constants
- packages/pike-lsp-server/src/services/resolution-cache-persistence.ts: Added fs.stat size guard in loadResolutionCache, data.length guard after parse, serialized size guard in saveResolutionCache
- packages/pike-lsp-server/src/scenarios/resolution-cache-persistence.test.ts: Added 3 scenario tests for oversized file, oversized data, and oversized save skip
- packages/pike-lsp-server/src/tests/services/resolution-cache-persistence.test.ts: Added 2 mock-based tests for stat rejection and data length rejection
