# KB-2080: Replace console.warn with Logger in RXML Parser

## Summary

`parser.ts` was the only file in `features/rxml/` using raw `console.warn()` instead of the project's Logger class. Added Logger import and instance, replaced the console.warn call with `log.warn()`, and added a test verifying console.warn is not called on parse failure.

## Key Files Changed

- packages/pike-lsp-server/src/features/rxml/parser.ts: Added `import { Logger } from '@pike-lsp/core'`, added `const log = new Logger('RXMLParser')`, replaced `console.warn(...)` with `log.warn(...)` using structured context object
- packages/pike-lsp-server/src/tests/features/rxml/parser.test.ts: Added test `'should use Logger instead of console.warn on parse failure'` that monkeys console.warn to verify it is never called during parse errors
