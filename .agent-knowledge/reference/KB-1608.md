# KB-1608: Replace regex defvar scanning with character-based extraction

## Summary

`getDefvarDefinitionIndex()` in `definition-provider.ts` used `/defvar\s*\(\s*["']([^"']+)["']/g` to extract defvar names from all workspace Pike files. This regex failed on escaped quotes and was a parsing anti-pattern. Replaced with `extractDefvarNamesFromContent()` — a character-based scanner that finds `defvar` keyword, skips whitespace, then extracts the quoted name literal while handling backslash escapes. No public API changes; all existing tests pass unchanged.

## Key Files Changed

- packages/pike-lsp-server/src/features/rxml/definition-provider.ts: Replaced regex loop with `extractDefvarNamesFromContent()` character scanner in `getDefvarDefinitionIndex()`. Removed unused `extractDefvarsFromTokens`, `RawDefvar`, and `PikeToken` imports.
