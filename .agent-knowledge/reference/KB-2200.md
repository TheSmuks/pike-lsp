# KB-2200: Fix pike-test CI failures on PR #2200

## Summary
Three distinct Pike test failures prevented CI from passing on both Pike 8.1116 and latest:
1. `Rename.pike` had an off-by-one loop (`j <= nth` should be `j < nth`) and missing bounds check on `search_start`, causing `search()` to crash with "Start must not be greater than the length of the string" on multi-line code.
2. `RoxenStubs.pmod/module.pike` had self-referential constants (`constant Roxen = Roxen`) that always resolved to 0. Fixed by removing the constants and making module.pike a simple index; sub-modules are accessed directly via `LSP.RoxenStubs.Roxen` and `LSP.RoxenStubs.RXML`.
3. `RXML.pike` used Pike 8.1+ foreach separator syntax (`foreach (tags; Tag t)`) which is a syntax error in Pike 8.0.1116. Changed to standard `foreach (tags, Tag t)`.

## Key Files Changed
- `pike-scripts/LSP.pmod/Rename.pike`: Fixed loop bound and added search_start bounds check
- `pike-scripts/LSP.pmod/RoxenStubs.pmod/module.pike`: Removed self-referential constants, made plain index
- `pike-scripts/LSP.pmod/RoxenStubs.pmod/RXML.pike`: Changed foreach separator from `;` to `,`
- `pike-scripts/LSP.pmod/RoxenStubs.pmod/Roxen.pike`: Extended defvar() signature to accept 5 args
- `test/tests/roxen-stubs-tests.pike`: Updated export tests to resolve sub-modules directly
