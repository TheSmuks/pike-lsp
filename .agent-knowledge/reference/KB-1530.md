# KB-1530: Split formatting-service.ts to comply with 500-line limit

## Summary

The formatting-service.ts file was 521 lines, exceeding the project's 500-line limit. It was split into four files: formatting-profiles.ts (types + predefined profiles), formatting-transformations.ts (brace style, operator spacing, line length, merge helpers), formatting-indentation.ts (indent computation), and the original formatting-service.ts retained as the orchestrator that re-exports all public symbols. No behavior changes.

## Key Files Changed

- packages/pike-lsp-server/src/services/formatting/formatting-profiles.ts: extracted FormattingOptions, FormattingProfile interfaces and PREDEFINED_PROFILES constant
- packages/pike-lsp-server/src/services/formatting/formatting-transformations.ts: extracted applyBraceStyleTransformation, applyOperatorSpacing, applyLineLengthLimit, mergeAndSortEdits
- packages/pike-lsp-server/src/services/formatting/formatting-indentation.ts: extracted computeIndentEdits
- packages/pike-lsp-server/src/services/formatting-service.ts: rewrote as orchestrator importing from the three new modules, re-exporting all public symbols
