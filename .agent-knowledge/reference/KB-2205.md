# KB-2205: Restore per-document setPending in batch config-change validation

## Summary
The batch config-change validation removed individual `documentCache.setPending(uri, promise)` calls, causing `waitFor` to return stale data when a client requests diagnostics/symbols for a document currently being validated inside the batch. Fixed by creating a per-document deferred promise inside the batch loop that resolves after each document's validation completes.

## Key Files Changed
- packages/pike-lsp-server/src/features/diagnostics/lifecycle.ts: Added per-document `setPending` with deferred promise resolution inside batch loop
- packages/pike-lsp-server/src/services/pike-introspection.ts: Reverted unrelated formatting-only change (arrow function parens)
