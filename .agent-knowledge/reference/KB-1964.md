# KB-1964: Replace unsafe error.code cast in readDocumentText

## Summary

`readDocumentText()` in `pike-introspection.ts` extracted `error.code` via `'code' in error` followed by an unchecked `as NodeJS.ErrnoException` cast. Replaced with the same `instanceof Error && 'code' in error && error.code === 'ENOENT'` pattern used in `resolution-cache-persistence.ts` (PR #1880), eliminating the unsafe cast entirely.

## Key Files Changed

- packages/pike-lsp-server/src/services/pike-introspection.ts: Replaced 5-line unsafe code extraction with single-line instanceof check in readDocumentText catch handler
