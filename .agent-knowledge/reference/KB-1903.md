# KB-1903: Replace Record cast with direct field access in getSymbolDetail()

## Summary

`getSymbolDetail()` in `symbols.ts` cast `PikeSymbol` to `Record<string, unknown>` to access fields like `returnType`, `argTypes`, `type`, `inherited`, etc. This was replaced with direct field access (since those fields exist on `PikeSymbol`) and `symbol.kind === 'method'` narrowing with `const m = symbol as PikeMethod` for method-specific fields. All `.name` type access was replaced with `formatPikeType()` since `PikeType` is a union of ~17 types and only `PikeNameType` has `.name`. Tests were updated to use proper `PikeSymbol`/`PikeMethod` types instead of `as any` casts.

## Key Files Changed

- packages/pike-lsp-server/src/features/symbols.ts: Added `PikeMethod` import, added `formatPikeType` import, replaced `as unknown as Record<string, unknown>` cast with direct field access and kind-based narrowing, replaced `.name` type access with `formatPikeType()` calls
- packages/pike-lsp-server/src/tests/features/symbols.test.ts: Replaced `as any` casts with proper `as PikeSymbol`/`as PikeMethod` types, added `kind: 'method'` to method test fixtures, updated null argType test from empty object to `null`, updated imports
