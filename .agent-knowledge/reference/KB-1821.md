# KB-1821: Split hierarchy.ts to enforce 500-line file limit

## Summary

`hierarchy.ts` (895 lines) bundled call hierarchy handlers, type hierarchy handlers, and multiple utility functions into a single file. Split into four files: `hierarchy-utils.ts` (shared utilities: isCallable, getCallableSymbolKind, formatInheritanceDetail, getSymbolsForUri, getKnownUris, buildSymbolPositionsFromTokens, loadClosedWorkspaceFile, resolveClassDefinition), `call-hierarchy.ts` (onPrepare, onIncomingCalls, onOutgoingCalls), `type-hierarchy.ts` (onPrepare, onSupertypes, onSubtypes), and `hierarchy.ts` (barrel exporting `registerHierarchyHandlers`). All consumers import only `registerHierarchyHandlers` from `hierarchy.ts`, so no external changes were needed. Utilities that were closures over `services` were converted to accept `services` as an explicit parameter.

## Key Files Changed

- `packages/pike-lsp-server/src/features/hierarchy.ts`: Replaced 895-line monolith with 33-line barrel that composes call-hierarchy and type-hierarchy registration.
- `packages/pike-lsp-server/src/features/hierarchy-utils.ts`: New file with shared utilities extracted from hierarchy.ts (264 lines).
- `packages/pike-lsp-server/src/features/call-hierarchy.ts`: New file with call hierarchy handlers (398 lines).
- `packages/pike-lsp-server/src/features/type-hierarchy.ts`: New file with type hierarchy handlers (301 lines).
