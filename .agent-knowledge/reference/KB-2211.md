# KB-2211: Replace cross-file rename full cache scan with index lookup

## Summary

The cross-file rename path in `rename.ts` materialized the entire `documentCache` entries array on every rename request (O(N) allocation + iteration). Replaced with `workspaceIndex.getUrisForSymbolName()` which uses the existing `symbolLookup` map for O(1) lookup by symbol name, returning only the K URIs that actually contain the symbol.

## Key Files Changed

- packages/pike-lsp-server/src/workspace-index.ts: Added `getUrisForSymbolName(symbolName)` public method leveraging existing `symbolLookup` index
- packages/pike-lsp-server/src/features/editing/rename.ts: Replaced `Array.from(documentCache.entries())` loop with `workspaceIndex.getUrisForSymbolName(oldName)` + `documentCache.get(uri)` per candidate
- packages/pike-lsp-server/src/workspace-index.test.ts: Added 5 unit tests for `getUrisForSymbolName` (exact match, case-insensitive, no match, multi-file, removal)
