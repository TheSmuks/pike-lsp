# KB-1762: Remove hasCompleteIntrospection filter that drops valid inherits on partial failure

## Summary

`buildRelations()` in `pike-introspection.ts` set `hasCompleteIntrospection = true` whenever any introspected inherits existed, then skipped any inherit symbol not found in the introspected names set. On partial introspection failure (some inherits resolved, others unreachable), valid inherits were silently dropped, causing incomplete call hierarchy and implementation results. Removed the guard entirely — the subsequent introspection lookup that sets `inheritedPath` already handles missing sources gracefully.

## Key Files Changed

- packages/pike-lsp-server/src/services/pike-introspection.ts: Removed `introspectedNames` variable, `hasCompleteIntrospection` variable, the guard block at lines 225-227, and the now-dead `collectInheritanceNames()` private method (16 lines total removed).
