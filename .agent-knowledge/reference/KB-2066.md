# KB-2066: Batch evictOlderThan invalidations and combined evict+serialize

## Summary

`CompilationCache.evictOlderThan` iterated expired entries then called `this.cache.delete(uri)` in a second loop — each `delete()` is a separate Map lookup. Added `LRUCache.deleteBatch(keys)` which removes multiple keys in a single pass, and changed `evictOlderThan` to use it. Also added `evictAndSerialize(maxAgeMs, now)` that performs eviction and serialization in a single pass over cache entries, avoiding the double iteration when both operations are needed (e.g., during persistence).

## Key Files Changed

- packages/pike-lsp-server/src/utils/lru-cache.ts: Added `deleteBatch(keys)` method — removes multiple keys in one pass, returns count of actually removed entries
- packages/pike-lsp-server/src/services/compilation-cache.ts: Changed `evictOlderThan` to use `cache.deleteBatch(expired)` instead of per-entry `cache.delete()`. Added `evictAndSerialize()` method for single-pass evict + serialize
- packages/pike-lsp-server/src/utils/lru-cache.test.ts: Added 4 tests for `deleteBatch` (basic, missing keys, empty array, weighted size tracking)
- packages/pike-lsp-server/src/scenarios/compilation-cache-invalidation.test.ts: Added 4 tests for `evictAndSerialize` (partial eviction, no eviction, full eviction, dependency edge cleanup)
