# KB-2066: Batch evictOlderThan invalidations via deleteBatch

## Summary

`CompilationCache.evictOlderThan` iterated expired entries then called `this.cache.delete(uri)` in a second loop — each `delete()` is a separate Map lookup. Added `LRUCache.deleteBatch(keys)` which removes multiple keys in a single pass, and changed `evictOlderThan` to use it. An initial `evictAndSerialize` method was also added but was removed during review as it had no callers — the persistence path (`saveResolutionCache`) accepts a pre-serialized string and never calls `evictOlderThan` + `serialize()` sequentially.

## Key Files Changed

- packages/pike-lsp-server/src/utils/lru-cache.ts: Added `deleteBatch(keys)` method — removes multiple keys in one pass, returns count of actually removed entries
- packages/pike-lsp-server/src/services/compilation-cache.ts: Changed `evictOlderThan` to use `cache.deleteBatch(expired)` instead of per-entry `cache.delete()`
- packages/pike-lsp-server/src/utils/lru-cache.test.ts: Added 4 tests for `deleteBatch` (basic, missing keys, empty array, weighted size tracking)
- packages/pike-lsp-server/src/scenarios/compilation-cache-invalidation.test.ts: Tests for evictAndSerialize removed during review (no callers)
