# KB-2207: Remove broken getInheritedMembers from rename.ts

## Summary

`getInheritedMembers` claimed to trace inheritance chains but actually just filtered all symbols by name, producing false-positive "inherited members" for unrelated scopes. The function was only used for a debug log and did not affect rename edits. Removed the function, its call site, its misleading header comment, and two bogus scenario tests.

## Key Files Changed

- packages/pike-lsp-server/src/features/editing/rename.ts: Removed broken `getInheritedMembers` function, its only call site (debug log block), and misleading "Inherited member renaming support" header line.
- packages/pike-lsp-server/src/scenarios/rename-cross-file.test.ts: Removed "Inherited member rename" describe block containing two tests that validated the broken name-matching logic against inline mock data.
