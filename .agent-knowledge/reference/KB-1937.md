# KB-1937: Remove unused lastModified field from ResolvedInclude

## Summary

The `lastModified` field on `ResolvedInclude` was set to `Date.now()` during include resolution but never read for cache invalidation or any other logic. `IncludeResolver.invalidate()` only removes entries by path. All consumers only access `originalPath`, `resolvedPath`, and `symbols`. Removed the field from the type, all assignments in `include-resolver.ts`, and updated tests that asserted on it.

## Key Files Changed

- packages/pike-lsp-server/src/core/types.ts: Removed `lastModified` field from `ResolvedInclude` interface
- packages/pike-lsp-server/src/services/include-resolver.ts: Removed `lastModified` from return type of `resolveAndCache()`, all assignments, and `const now = Date.now()`
- packages/pike-lsp-server/src/tests/services/include-resolver.test.ts: Replaced lastModified equality test with resolvedPath equality test
- packages/pike-lsp-server/src/scenarios/document-links.test.ts: Removed `lastModified` from ResolvedInclude test fixtures
