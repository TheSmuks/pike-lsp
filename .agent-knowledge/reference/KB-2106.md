# KB-2106: Missing parseFn mock in RXML tests after symbols-required migration

## Summary
PR #2106 made the `symbols` parameter required in `findTagFunctionsInCode` and removed the string-scan fallback. Test files `rxml-cache-invalidation.test.ts` and `rxml-handler-registration.test.ts` were updated to pass `parseFn` but the `parseFn` variable was never defined, causing `ReferenceError: parseFn is not defined`. Additionally, test fixture code used space-form syntax (`simpletag foo()`) which `computeNameOffset` cannot resolve — it requires the underscore form (`simpletag_foo()`) to match symbol names.

## Key Files Changed
- `packages/pike-lsp-server/src/tests/rxml-cache-invalidation.test.ts`: Added `mockParseFn` that extracts `simpletag_/container_` method symbols from Pike source; changed fixture code to underscore form.
- `packages/pike-lsp-server/src/tests/rxml-handler-registration.test.ts`: Same `mockParseFn` addition.
