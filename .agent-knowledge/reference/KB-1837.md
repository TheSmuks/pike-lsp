# KB-1837: Clean up dead workspaceScanner references post-migration

## Summary
After PR #1836 removed WorkspaceScanner (replaced by WorkspaceIndex), many test files still referenced `workspaceScanner` in mock service objects, interface definitions, and `createMockServices()` calls. These were silently ignored since `MockServicesOverrides` no longer has a `workspaceScanner` field. Additionally, `pike-introspection.ts` had a duplicate unreachable `return 'unknown'` (merge artifact).

## Key Files Changed
- packages/pike-lsp-server/src/services/pike-introspection.ts: Removed duplicate `return 'unknown'` on line 115 (line 114 already returns).
- packages/pike-lsp-server/src/tests/hierarchy/workspace-inheritance.test.ts: Replaced 3 `workspaceScanner` overrides with `workspaceIndex` overrides providing `getAllDocumentUris`. Removed 1 dead `mockWorkspaceScanner` variable.
- packages/pike-lsp-server/src/tests/runtime/server-runtime-workspace-folders.test.ts: Removed dead `workspaceScanner` variable and property from `registerServerRuntimeHandlers()` call.
- packages/pike-lsp-server/src/tests/runtime/server-runtime-progress.test.ts: Removed 2 dead `workspaceScanner` variables and 2 properties from `registerServerRuntimeHandlers()` calls.
- packages/pike-lsp-server/src/tests/editing/completion-provider.test.ts: Removed `createMockWorkspaceScanner()` function and 3 `workspaceScanner` properties from mock services.
- packages/pike-lsp-server/src/tests/navigation/references-provider.test.ts: Removed `workspaceScanner?: any` from `SetupOptions` interface and `workspaceScanner: opts.workspaceScanner` from `createMockServices()`.
- packages/pike-lsp-server/src/tests/navigation/references-scope.test.ts: Removed `workspaceScanner?: any` from `ScopeTestOptions` interface and `workspaceScanner: opts.workspaceScanner` from `createMockServices()`.
