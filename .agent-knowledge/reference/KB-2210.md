# KB-2210: Index class symbols for member-access completion lookup

## Summary

`resolvePikeContextMemberAccess` and `resolveMembersFromWorkspace` in `completion-member-access.ts` iterated every document in `documentCache` calling `symbols.find()` on each — O(files x symbols) per keystroke. Replaced both scans with `WorkspaceIndex.findClassUri()` (O(1) via `symbolLookup`) and `getClassSymbol()` (O(symbols in one document)). Also cleaned up the now-unused `documentCache` parameter from `resolveArrowWorkaround`.

## Key Files Changed

- packages/pike-lsp-server/src/workspace-index.ts: Added `findClassUri()` and `getClassSymbol()` public methods leveraging existing `symbolLookup` index
- packages/pike-lsp-server/src/features/editing/completion-member-access.ts: Replaced two linear scans with index lookups; changed `resolveMembersFromWorkspace` to accept `Services` instead of `documentCache`; removed unused `documentCache` param from `resolveArrowWorkaround`
- packages/pike-lsp-server/src/features/editing/completion.ts: Updated call site to match `resolveArrowWorkaround` signature change
- packages/pike-lsp-server/src/workspace-index.test.ts: Added tests for `findClassUri` (basic, case-insensitive, non-existent, disambiguate class vs function, removal) and `getClassSymbol` (with children, wrong URI)
